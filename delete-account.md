# Suppression de compte FlowDay

Pour supprimer vos données FlowDay :

1. **Données Google Drive** : Rendez-vous sur [myaccount.google.com/permissions](https://myaccount.google.com/permissions), trouvez FlowDay et cliquez "Supprimer l'accès". Toutes vos données seront supprimées du Google Drive.

2. **Données locales** : Désinstallez l'application FlowDay de votre appareil.

3. **Contact** : Pour toute demande de suppression, contactez flowday.app@outlook.com

Délai de traitement : 30 jours maximum.
